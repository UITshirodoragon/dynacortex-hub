Hiện trạng Python SDK và firmware API của MyArm Master 750

Trang này chỉ phản ánh hiện trạng source trong pymycobot.zip đang xét. Trọng tâm không phải đề xuất kiến trúc mới, mà là đọc trực tiếp các file Python liên quan đến MyArm Master 750 để xác định: module nào tham gia, class nào đại diện cho firmware API nào, method nào gọi protocol nào, tham số được validate ở đâu, giá trị trả về được decode như thế nào, và các điểm không thống nhất giữa docs/source/firmware quan sát thực tế.

Important

Trong tài liệu này, mọi miền giá trị được viết theo dạng \([a,b]\). Góc luôn ghi rõ \(\mathrm{rad}\) và \(^\circ\) khi có chuyển đổi. Tọa độ Cartesian của API firmware dùng \(\mathrm{mm}\) ở mức Python API, trong khi URDF/ROS2 dùng \(\mathrm{m}\) và \(\mathrm{rad}\).

3. Protocol và đơn vị ở tầng codec

DataProcessor._mesg() tạo frame lệnh theo dạng:

\[ \mathrm{frame} = [0xFE, 0xFE, L, c, d_1, d_2, \ldots, d_n, 0xFA] \tag{1}\]

Trong đó \(c\) là command/genre, \(d_i\) là data byte, và với robot không dùng CRC thì source đặt:

\[ L = n + 2 \tag{2}\]

Điều này tương ứng với common.py:L568-L582: LEN = len(command_data) + 2, sau đó append HEADER, HEADER, LEN, genre, data, FOOTER.

Các phép encode/decode quan trọng nằm ở common.py:L612-L625:

\[ \theta_\mathrm{int} = \lfloor 100\theta_{^\circ}\rfloor, \qquad x_\mathrm{int} = \lfloor 10x_\mathrm{mm}\rfloor \tag{3}\]

\[ \theta_{^\circ}=\frac{\theta_\mathrm{int}}{100}, \qquad x_\mathrm{mm}=\frac{x_\mathrm{int}}{10} \tag{4}\]

Đổi sang radian để đối chiếu ROS2/URDF:

\[ \theta_\mathrm{rad}=\frac{\pi}{180}\theta_{^\circ} \tag{5}\]

# Source: pymycobot/common.py:L612-L625
def _angle2int(self, angle):
    return int(angle * 100)

def _coord2int(self, coord):
    return int(coord * 10)

def _int2angle(self, _int):
    return round(_int / 100.0, 3)

def _int2coord(self, _int):
    return round(_int / 10.0, 2)
Note

Ở Python SDK, angle arguments được hiểu là degree \(^\circ\) ở bề mặt API, còn ROS2 JointState.position và URDF limits dùng radian \(\mathrm{rad}\). Cartesian coordinate trong MyArmMControl dùng \(\mathrm{mm}\) ở ba phần tử đầu; URDF dùng \(\mathrm{m}\).

5.1. Semantics của _mesg() với MyArmM

MyArmM dùng MyArmMCProcessor._mesg() trong myarm_api.py:L95-L178. Nếu method không truyền has_reply=True, source chỉ write frame rồi return None:

# Source: pymycobot/myarm_api.py:L106-L116
real_command, has_reply, _async = super(MyArmMCProcessor, self)._mesg(genre, *args, **kwargs)
with self.lock:
    self._write(self._flatten(real_command))

    if not has_reply:
        ...
        return None

    data = self._read(genre)
    res = self._process_received(data, genre, arm=8)

Vì vậy set_joints_angle() là fire-and-forget ở source-level, còn get_joints_angle(), is_robot_moving(), get_joints_max()… có reply vì method truyền has_reply=True.

5.2. Method riêng trong myarmm.py — format rút gọn dễ đọc

Các method dưới đây là API riêng của MyArmM, tức lớp dùng cho Shake/joint-servo API. Format được rút gọn theo đúng các trường cần đọc: ý nghĩa kỹ thuật, protocol/code, validation, encode/decode và return/reply. Catalog CSV vẫn được giữ ở assets/tables/myarmm_method_catalog_v008.csv để tra cứu bằng script.

Note

Với MyArmM, những method không truyền has_reply=True đi qua MyArmMCProcessor._mesg() theo kiểu ghi frame xuống serial rồi trả về None. Vì vậy phần Return/reply cần đọc cùng dòng source của method, không chỉ đọc tên protocol.

# Source: pymycobot/myarmm_control.py:L70-L77
def _mesg(self, genre, *args, **kwargs):
    kwargs["has_reply"] = True
    real_command, has_reply, _ = super(MyArmMProcessor, self)._mesg(genre, *args, **kwargs)
    real_command = self._flatten(real_command)
    self._write(real_command)

    with self.lock:
        return self._read_genre_result(genre)

Về mặt source, đây là khác biệt cơ bản với MyArmM: MyArmMControl đọc response cho mọi command. Khi phân tích lỗi runtime, cần xét thêm khả năng latency hoặc stale reply ở serial buffer, chứ không chỉ xét baudrate.

# Source: pymycobot/myarmm_control.py:L294-L311
def write_coords(self, coords, speed, mode=None):
    self.calibration_parameters(coords=coords, speed=speed)
    coord_list = []
    for idx in range(3):
        coord_list.append(self._coord2int(coords[idx]))
    for angle in coords[3:]:
        coord_list.append(self._angle2int(angle))
    if mode is not None:

    else:
        return self._mesg(ProtocolCode.SEND_COORDS, coord_list, speed)

7. MyArmM và MyArmMControl có gửi cùng message không?

Một số method dùng cùng ProtocolCode và cùng codec của DataProcessor. Ví dụ:

Chức năng MyArmM MyArmMControl ProtocolCode Ý nghĩa
Gửi joint vector set_joints_angle(angles, speed) write_angles(angles, speed) SEND_ANGLES = 0x22 Payload angle được encode bằng \(\theta_\mathrm{int}=\lfloor100\theta_{^\circ}\rfloor\).
Đọc joint vector get_joints_angle() get_angles() GET_ANGLES = 0x20 Trả về list angle \(^\circ\).
Dừng motion stop_robot() stop() STOP = 0x29 MyArmMControl.stop() có reply vì _mesg ép has_reply=True.
Đọc moving flag is_robot_moving() is_moving() IS_MOVING = 0x2B Return single value.
Encoder single get_servo_encoder(servo_id) get_encoder(joint_id) GET_ENCODER = 0x3B Cùng command nhưng tên argument khác nhau.
Encoder vector get_servos_encoder() get_encoders() GET_ENCODERS = 0x3D Raw count.

Tuy nhiên không thể kết luận hai class thay thế trực tiếp cho nhau, vì source khác ở bốn điểm:

  1. MyArmMControl._mesg() luôn đọc response; MyArmM chỉ đọc khi method truyền has_reply=True.
  2. Validation dùng class_name, nên MyArmM và MyArmMControl dùng limit/length khác nhau.
  3. MyArmMControl có coord_id, coord_min, coord_max; MyArmM không có coordinate range trong robot_info.py.
  4. MyArmMControl có frame/planner/config API; MyArmM tập trung joint/servo/status.
Warning

Nếu robot đang nạp Coordinate firmware nhưng gọi MyArmM, một số command trùng protocol có thể vẫn đi xuống firmware. Tuy nhiên source-level không đảm bảo an toàn về reply behavior và validation. Đặc biệt MyArmM.set_joints_angle() không đọc ACK, trong khi Coordinate firmware có thể trả response cho command tương tự. Điều này có thể để lại frame trong serial buffer cho lần đọc tiếp theo.
