Hiện trạng ROS2 SDK/demo package của MyArm Master 750

Trang này phản ánh package ROS2 myArm/myarm_m750 và URDF/Xacro trong mycobot_ros2 đã trích ra. Nội dung tập trung vào nhà sản xuất đang demo gì, node nào gọi API nào, URDF/Xacro ghi gì, và các khoảng trống kỹ thuật trong source.

Warning

Package myarm_m750 trong source đang xét là demo ROS2/RViz đơn giản. Source không chứa ros2_control hardware plugin, joint_trajectory_controller, FollowJointTrajectory action server hoặc MoveIt2 config đầy đủ cho robot thật.

1. Package inventory

URDF/Xacro nằm ở mycobot_description/urdf/myarm_m750/.

2. Flow ROS2 thật sự trong demo đọc joint

read_control.py là file khớp nhất với pymycobot source. Node tạo timer \(T=0.02~\mathrm{s}\), tương đương:

\[ f = \frac{1}{T} = 50~\mathrm{Hz} \tag{1}\]

Trong source:

angles = self.mam.get_joints_angle()
gripper_angle = angles.pop(6)
gripper_angle /= -3500
angle = [a / 180 * pi for a in angles]
angle.append(gripper_angle)
joint_state.position = angle

Tức là \(q_1\) đến \(q_6\) được đổi bằng \(q_i[\mathrm{rad}] = \frac{\pi}{180}q_i[^\circ]\). Riêng gripper dùng \(g=e_7/(-3500)\), source không giải thích hệ số này.

6. ros2_control và MoveIt2 execution: trạng thái source

Issue Evidence in source Technical impact
Không có MyArmMControl trong package M750 Import audit trong myarm_m750 thấy MyArmM hoặc legacy MyArm, không thấy MyArmMControl. ROS2 demo không phản ánh Coordinate API class hiện tại.
Không có ros2_control hardware interface Không thấy <ros2_control> tag, hardware_interface::SystemInterface, controller YAML. Package không phải control stack chuẩn.
Không có MoveIt2 config đầy đủ Không thấy SRDF, kinematics.yaml, ompl_planning.yaml, move_group launch. Không có planning/execution pipeline đầy đủ.
API mismatch trong scripts điều khiển slider_control.py gọi send_angles; simple_gui.py gọi send_coords; MyArmM không có các method này. Có thể lỗi runtime với SDK v4.0.4/v4.0.5.
URDF limits lệch docs/SDK URDF joint1..6 giới hạn rad khác docs Coordinate và robot_info.py. Tool đọc URDF sẽ validate khác Python SDK/firmware.
Gripper biểu diễn khác giữa URDF và SDK URDF dùng prismatic gripper, gripper_r; SDK/docs có J7 angle/potential. Không có ánh xạ một-một hiển nhiên.

package.xml có thể khai báo controller_manager, nhưng khai báo dependency không đồng nghĩa source đã có hardware interface hoặc controller YAML.

MoveIt2 -> FollowJointTrajectory -> joint_trajectory_controller -> hardware_interface -> pymycobot -> robot

Graph trên không xuất hiện trong package đang xét. Flow thật sự giống hơn:

robot thật -> pymycobot MyArmM -> read_control.py -> /joint_states -> robot_state_publisher -> RViz2

7. ROS2 graph và ý nghĩa kỹ thuật

ROS2 là middleware cho robotic applications; nó cung cấp computation graph gồm node, topic, service, action và tooling để quan sát/debug (ros2programming2025?). Với package M750 này, graph source-level có hai nhóm chính:

Đây là graph visualization/follow, không phải trajectory execution hoặc closed-loop controller.

8. Trạng thái tổng hợp

  • Phần đáng tin nhất của package là read_control.py: dùng MyArmM, đọc độ, publish rad lên /joint_states.
  • Package không dùng MyArmMControl, nên không đại diện cho Coordinate firmware/API hiện tại.
  • Nhiều file điều khiển gọi method không tồn tại trong MyArmM source v4.0.4.
  • URDF/Xacro có đơn vị và limits riêng; các limits này lệch docs và Python SDK.
  • Gripper trong URDF là prismatic, trong demo lại có scaling \(g=e_7/(-3500)\) không được giải thích bằng calibration source.
  • Không thấy source cho ros2_control, joint_trajectory_controller, FollowJointTrajectory hoặc MoveIt2 config đầy đủ.
