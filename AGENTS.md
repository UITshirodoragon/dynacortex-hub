# Agent Instructions

Before editing this Quarto documentation project, read `.agents/skill_quarto_docs.md`.

Use the repo-local tools in `.agents/tools/` when creating or checking pages:

- `python .agents/tools/check_quarto_docs.py`
- `python .agents/tools/create_quarto_topic.py <section-folder> <topic-slug> --title "Title"`

Work from source files (`*.qmd`, `_quarto.yml`, `templates/`, `references/`) and do not hand-edit generated output in `docs/` or `_site/`.

Ghi nhớ ngắn: sửa source, giữ văn phong tiếng Việt + thuật ngữ kỹ thuật English, không tự revert thay đổi sẵn của người dùng.
